## 🔍 Core Features

- **📂 10 Cold Case Investigations (L0–L9)**  
  A fully structured, narrative-driven curriculum guiding detectives from basic queries to enterprise database operations:
  - **L0: Precinct Orientation** — Database anatomy, table schemas, and column projection (`SELECT *`, `SELECT col1, col2`).
  - **L1: Filtering the Lineup** — Isolate suspects matching physical profiles using `WHERE`, logical `AND`/`OR`, and `LIKE %pattern%`.
  - **L2: Midnight Heist** — Bridge digital access badges to suspect files using Primary & Foreign Keys with `INNER JOIN`.
  - **L3: Syndicate Financial Audit** — Identify money-laundering hubs using aggregate functions (`COUNT`, `SUM`, `AVG`) and `GROUP BY ... HAVING`.
  - **L4: Infiltrating the Inner Sanctum** — Benchmark anomalous operative payouts using dynamic nested subqueries and `WHERE column IN (...)`.
  - **L5: Evidence Room Tampering** — Repair manipulated forensics and prune rogue logs with Data Manipulation Language (`INSERT`, `UPDATE`, `DELETE`).
  - **L6: The Vanishing Operative** — Trace missing operatives and unassigned safehouses without dropping records using `LEFT JOIN` and `COALESCE()`.
  - **L7: Architect's Blueprint** — Accelerate surveillance lookups and mask classified intelligence using `CREATE INDEX` and `CREATE VIEW`.
  - **L8: Laundering the Shadow Ledger** — Implement multi-condition forensic profiling using conditional logic (`CASE WHEN ... THEN ... ELSE ... END`).
  - **L9: Grand Syndicate Takedown** — Safely execute multi-table warrants and seize illicit holdings in an atomic transaction block (`BEGIN TRANSACTION ... COMMIT`).

- **⚡ Client-Side WebAssembly Query Engine**  
  Powered by `sql.js` (SQLite compiled to WebAssembly), enabling millisecond-fast query execution and data manipulation directly in the browser with zero remote database latency.

- **🎯 Dataset Equivalence Evaluator**  
  Intelligent evaluation engine tests the actual dataset and relational rows returned by the user query rather than enforcing rigid string matching—empowering multiple valid SQL syntactical solutions.

- **🏆 Live Precinct Directory & Leaderboard**  
  Real-time Cloud Firestore integration streams detective scores, ranks, earned badges, and online presence heartbeats directly from central precinct logs without page reloads.

- **📖 Detective Field Journal**  
  An interactive, built-in RDBMS reference handbook providing unlockable syntax cards, schema diagrams, and lead investigator tips with one-click code snippet injection into the query editor.

- **🎨 Ambient Low-Poly Aesthetic**  
  A distraction-free, atmospheric forensic workspace designed with a natural Sage Green, Pale Sand, and Terracotta palette, low-poly mountain silhouettes, and faceted geometric awards.
